Use them to see what goes wrong, not to compare how often.

Where this comes from

NHTSA publishes every complaint owners file through nhtsa.gov and every recall makers report. We took the motorcycle entries, matched each complaint to a model using its VIN where possible (86% of them) and the model name otherwise, and grouped NHTSA's technical part codes into plain English. Model names are as NHTSA and the makers use them, so some trims of the same bike appear separately.
